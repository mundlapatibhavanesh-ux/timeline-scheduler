# 📱 Mobile-First Timeline Scheduler & Alarm

A lightweight, fully responsive web application optimized explicitly for mobile displays. This tool allows users to map out their work steps, pool tasks in a queue, and execute them with manual timeline control.

---

## 🚀 Mobile Optimization Features

* **📱 Touch-Friendly Layout:** Features enlarged buttons, inputs, and picker elements designed for thumb interaction without misclicks.
* **📐 Bottom-Sheet Modals:** The Calendar Scope configuration slides naturally from the bottom of the display, mirroring native iOS and Android system aesthetics.
* **🔒 Dynamic Viewport Control:** Embedded hardware view-scaling locks the browser viewport, preventing unwanted text auto-zoom glitches when typing on smartphone screens.
* **🔋 Device-Side Engine Execution:** Countdown clocks, layout switches, and high-pitch `AudioContext` alarm buzzers run entirely inside the client browser. No background performance drain or external servers are required.

---

## 🛠️ Installation: Save as an App on Your Phone

You do not need an app store. You can pin this link directly to your mobile home screen to access it like a native app:

### For iPhone (Safari)
1. Open the live link in **Safari**.
2. Tap the **Share** icon (the box with an arrow pointing up at the bottom of the screen).
3. Scroll down the menu and tap **Add to Home Screen**.

### For Android (Chrome)
1. Open the live link in **Google Chrome**.
2. Tap the **Three Dots menu icon** (⋮) in the top-right corner.
3. Tap **Install app** or **Add to Home Screen**.
